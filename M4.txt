M4 — Крафт, база и автоматизация
CRAFT-001 — Recipe definitions

Критерии:

Рецепты data-driven.
Имеют input, output, station и unlock requirements.
Валидация обнаруживает неизвестные IDs.
Крафт атомарный.
CRAFT-002 — Workbench

Критерии:

Можно создать минимум три полезных объекта.
UI работает с контроллера.
Недостающие ресурсы понятны.
Нельзя потратить ресурсы без получения результата.
BUILD-001 — Размещение зданий

Критерии:

Есть preview.
Валидная и невалидная зона различаются.
Поворот работает с геймпада.
Нельзя поставить поверх игрока или другого здания.
Placement state не сохраняет временные preview nodes.
AUTO-001 — Лесопилка

Механика:

Периодически перерабатывает доступный wood input в processed planks.

Критерии:

Производство не привязано к FPS.
Есть входной и выходной inventory.
Есть понятный progress.
После загрузки производство восстанавливается корректно.
AUTO-002 — Автоматический сборщик

Механика:

Собирает обычные ресурсы в ограниченном радиусе.

Критерии:

Не собирает rare encounter rewards.
Не ворует предметы, предназначенные игроку.
Имеет понятные лимиты.
Offscreen-работа рассчитывается пакетно.
AUTO-003 — Связь зданий и хранилища

Критерии:

Ресурсы можно передавать между несколькими зданиями.
Первая версия не требует сложных конвейеров.
Игрок понимает направление потока.
Нет потери ресурсов при переполнении — используется safe output state.
AUTO-004 — Offline/offscreen simulation

Критерии:

Удалённые здания не симулируются каждый кадр.
Производство пересчитывается по времени и состоянию.
Результат ограничен storage capacity.
Нельзя эксплуатировать изменение системного времени.
Есть deterministic tests.
UPG-001 — Станция улучшения предметов

Критерии:

Предмет можно улучшить ограниченное число раз.
Стоимость растёт.
Улучшение не уничтожает affix.
Результат явно показывается до подтверждения.
Есть защита от accidental upgrade.
UPG-002 — Система качества и заточки

Пример:

+0 → +10

Критерии:

Усиление предсказуемо.
Нет полного разрушения предмета.
На высоких уровнях используется редкий ресурс.
Заточка не становится единственным источником силы.
Формула покрыта тестами.
Gate M4
Игрок вручную добывает ресурс.
Строит автоматизацию.
Старая рутина становится проще.
Освободившееся время тратится на бой, exploration и билд.
База не выглядит как обязательная бухгалтерия.
M5 — Rift и бесконечная прогрессия
RIFT-001 — Вход и выход из Rift

Критерии:

Есть безопасный вход.
Есть явный выход.
Игрок не теряет сохранение при аварийном выходе.
Rift использует отдельный deterministic seed.
Нельзя случайно заблокировать персонажа внутри.
RIFT-002 — Генератор encounter sequence

Первая версия:

Combat room
Combat modifier
Elite encounter
Reward
Boss or exit

Критерии:

Sequence воспроизводится по seed.
Невозможные комбинации отфильтрованы.
Каждая стадия имеет clear completion condition.
RIFT-003 — Scaling difficulty

Увеличивать:

enemy combinations;
elite affix;
environmental hazards;
reward modifiers;
ограничители билдов.

Не ограничиваться HP scaling.

Критерии:

Сложность читается до входа.
Рост награды сопоставим с риском.
Нет резкого невозможного скачка между соседними уровнями.
RIFT-004 — Rift rewards

Критерии:

Есть targeted loot tags.
Игрок может выбирать между двумя типами награды.
Повторный Rift имеет смысл.
Rift не делает обычные острова бессмысленными.
ELITE-001 — Elite modifier framework

Первый набор:

Vampiric;
Explosive;
Shielded;
Summoner;
Teleporter;
Berserk.

Критерии:

Modifier визуально читается.
Комбинации проверяются на совместимость.
Элитный враг не является только большим мешком HP.
BOSS-001 — Первый босс

Критерии:

Минимум три читаемые атаки.
Есть telegraph.
Есть смена поведения или фаза.
Босс проверяет движение и билд.
После победы выдаётся shard или legendary reward.
PROG-001 — Skill constellation foundation

Ветки:

Warrior;
Ranger;
Arcanist;
Inventor;
Druid;
Treasure Hunter.

Первая версия — по 3–4 узла, не полное дерево.

Критерии:

Можно смешивать ветки.
Respec возможен.
Есть минимум три build-changing узла.
Узлы data-driven.
PROG-002 — Weapon mastery

Критерии:

Мастерство растёт за использование оружия.
Есть разумный diminishing growth.
Бонусы не заставляют навсегда оставаться на первом выбранном оружии.
Нет бесконечного farm exploit на безопасной цели.
PROG-003 — Endless mastery foundation

Критерии:

После основного уровня остаётся долгосрочная прогрессия.
Награды ограничены diminishing returns.
Система не даёт неограниченный multiplicative scaling.
Есть cap или soft cap для опасных характеристик.
Gate M5
Игрок завершает Rift.
Получает reward, влияющий на билд или архипелаг.
Хочет поднять сложность.
Сложность растёт через новые ситуации, а не только HP.
Существует причина продолжать после сюжетного босса.
