============================================================
TASK-046 — MAIN CHARACTER ANIMATION OVERHAUL
============================================================

Outcome:
Replace placeholder or stiff main-character animations with a proper animation set that feels responsive and readable.

Motivation:
The player character is the thing the player watches 90% of the time. Bad animation poisons the whole experience.

In scope:
- Create/implement improved animation set for main character
- Idle animation
- Walk/run animation
- Basic attack animation
- Hit reaction animation
- Death animation
- Transition timing tuning

Out of scope:
- New combat mechanics
- Skill-specific advanced animations
- Full cinematic animation blending

Dependencies:
- Existing player controller
- Existing sprite/import pipeline

Acceptance criteria:
1. Character has distinct idle, move, attack, hit, and death animations.
2. Animation states transition correctly without visual popping.
3. Attack animation timing matches actual attack hit timing.
4. Movement animation reflects movement direction.
5. Animation remains readable at Steam Deck resolution.

Required tests:
- Integration: movement state transitions
- Integration: attack animation triggers once per attack
- Visual/controller: verify readability at 1280x800

Definition of done:
- Animations integrated
- No broken transitions
- Validation passed
- Visual evidence captured

TASK-049 — REMOVE CIRCLE AROUND MAIN CHARACTER
============================================================

Outcome:
Remove the circle around the main character and replace it with cleaner visual feedback only where necessary.

Dependencies:

- Existing interaction system

3. Readability does not regress.
4. The scene looks cleaner in screenshots and motion.

Required tests:
- Integration: interaction targeting still works

- Regression: no orphaned references to removed node/effect

============================================================
CORE PRINCIPLE
============================================================

Do not let the project become technically impressive but visually cheap or emotionally flat.

The player should feel:

“one more item,
one more island,
ten more minutes.”

The signature feature must be obvious in motion:

A player finds an island shard,
inspects its risks and rewards,
places it into the world,
and watches a new island materialize as part of their custom archipelago.
