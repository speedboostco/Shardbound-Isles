# Project Structure

- `src/domain/`: rendering-independent rules.
- `src/gameplay/`: composed gameplay scenes and scripts.
- `src/ui/`: presentation.
- `tests/unit`, `tests/integration`, `tests/simulation`: automated layers.
- `scripts/`: cross-platform command implementation.
- `docs/`: product and engineering sources of truth.
- `evidence/`: reproducible, non-generated summaries approved for review.
