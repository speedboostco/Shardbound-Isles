# Core Loop

Explore and gather; accept a weather-shaped Wayfinder contract; prepare Trail Rations for a safer, more productive expedition; resolve world events; fight and acquire equipment and island shards; equip, salvage, or transform loot; craft and automate mastered chores; install islands; meet their residents; choose how to stabilize or exploit them; defeat their Wardens; spend Expedition Marks; raise risk and reward; run rifts; repeat with new synergies.

The bootstrap first playable proved the smallest prefix: gather, fight, receive deterministic equipment, and see persistent run-state feedback in one arena. The current vertical slice extends that loop with crafting, automation, installable islands, a branching installed-island story, a persistent reward exchange, a boss, and repeatable rifts.
