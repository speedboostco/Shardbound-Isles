# Core Loop

Gather and fight; acquire equipment and island shards; equip, salvage, or transform loot; craft and automate mastered chores; install islands; raise risk and reward; run rifts; repeat with new synergies.

The bootstrap first playable proved the smallest prefix: gather, fight, receive deterministic equipment, and see persistent run-state feedback in one arena. The current vertical slice extends that same loop with crafting, automation, installable islands, a boss, and repeatable rifts.
