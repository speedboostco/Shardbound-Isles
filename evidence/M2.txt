M2 — Diablo-подобный лут
WPN-001 — Три архетипа оружия

Добавить:

sword;
bow;
wand.

Критерии:

Каждый архетип меняет стиль боя.
Они используют общую систему данных.
Управление работает на геймпаде.
Нет копирования всей боевой логики между оружиями.
ITEM-002 — Система редкости

Редкости:

Common
Magic
Rare
Epic
Legendary

Критерии:

Редкость управляет количеством и типом свойств.
Цвет не является единственным различием.
Распределение тестируется статистически.
Редкость не гарантирует, что предмет лучше любого более низкого уровня.
AFF-001 — Реестр affix-определений

Категории:

offensive;
defensive;
utility;
gathering;
production;
hybrid.

Критерии:

Affix имеет стабильный ID.
Есть ограничения по типу предмета.
Есть диапазон значений.
Есть weight.
Есть tags.
Нет hard-coded списка в UI или генераторе.
AFF-002 — Eligibility и конфликтующие свойства

Примеры:

модификатор стрел нельзя ставить на меч;
два взаимоисключающих elemental conversion нельзя использовать вместе;
legendary affix не занимает обычный affix-slot.

Критерии:

Невалидные комбинации не генерируются.
Правила покрыты unit-тестами.
Ошибочная definition выявляется validation script.
LOOT-002 — Полный генератор предметов

Pipeline:

Base type
→ item level
→ rarity
→ affix count
→ eligible pool
→ weighted selection
→ rolled values
→ final item

Критерии:

Полностью deterministic.
Не создаёт duplicate affix.
Не создаёт несовместимые свойства.
Генерация 10 000 предметов проходит без ошибок.
Результат сериализуем.
EQUIP-002 — Полноценные слоты экипировки

Минимум:

weapon;
helmet;
body;
boots;
ring;
amulet.

Критерии:

Слоты типизированы.
Статистика пересчитывается корректно.
Снятие предмета убирает его эффект.
Сохранение восстанавливает все слоты.
STAT-001 — Система производных характеристик

Минимум:

max health;
damage multiplier;
attack speed;
critical chance;
critical damage;
movement speed;
pickup radius;
gathering power.

Критерии:

Есть базовые, additive и multiplicative modifiers.
Порядок расчёта документирован.
Нет накопления бонусов при повторном экипировании.
Расчёты покрыты тестами.
UI-002 — Tooltip предмета

Критерии:

Показывает base stats.
Показывает affix.
Показывает legendary effect.
Значения форматируются единообразно.
Текст помещается на 1280×800.
Tooltip доступен с контроллера.
UI-003 — Сравнение предметов

Критерии:

Новый предмет сравнивается с экипированным.
Положительные и отрицательные различия понятны.
Поведенческие свойства не сводятся к фиктивному «item score».
Игрок может быстро надеть, оставить или разобрать предмет.
SALV-001 — Разбор ненужного лута

Критерии:

Предмет превращается в материалы.
Награда зависит от редкости и уровня.
Предмет уничтожается только после успешной операции.
Есть защита от случайного разбора экипированного или избранного предмета.
LEG-001 — Framework легендарных свойств

Критерии:

Легендарные эффекты подключаются как отдельные behavior-компоненты.
Не нужен giant switch по ID.
Поддерживаются события атаки, убийства, добычи и использования ресурса.
Эффект корректно отключается при снятии предмета.
Нет signal leak после замены экипировки.
LEG-002 — Легендарка: Chain Mining

Механика:

Удар киркой по ресурсу наносит часть урона ближайшим врагам и соседним ресурсам.

Критерии:

Есть cooldown или ограничение цепи.
Нет бесконечной рекурсии.
Эффект визуально понятен.
Работает deterministic.
Есть stress test.
LEG-003 — Легендарка: Burning Smelter

Механика:

Горящий враг после смерти автоматически переплавляет ближайшую руду или создаёт smelting charge.

Критерии:

Не создаёт бесконечный ресурсный цикл.
Чётко видно, почему эффект сработал.
Без подходящей цели эффект безопасно завершается.
LEG-004 — Легендарка: Living Arrows

Механика:

Некоторые стрелы выращивают временное атакующее растение.

Критерии:

Есть лимит активных растений.
Растения исчезают корректно.
Они не сохраняются как постоянные объекты.
Производительность стабильна.
LOOT-003 — Защита от мусорного лута

Добавить:

объединение одинаковых материалов;
ограничение количества world drops;
автоматический salvage низких редкостей как опция позднее;
loot filter architecture.

Критерии:

200 предметов не лежат бесконечно на земле.
Важный предмет визуально не теряется.
Очистка не удаляет легендарки без предупреждения.
Gate M2

Есть минимум 12 обычных affix.
Есть минимум 3 легендарных свойства.
Игрок может сравнить, надеть и разобрать предмет.
Один из legendary effects вызывает желание перестроить билд.
Лут не превращает игру в сортировку мусора
